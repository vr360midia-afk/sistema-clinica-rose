# Instruções de Autonomia do Agente

1. **Execução Proativa e Ágil de Comandos**: Sempre execute commits, testes e scripts automaticamente sem pedir confirmação prévia ao usuário. Priorize a velocidade de entrega sem rodar o empacotamento completo de produção (`npm run build`) a cada tarefa pequena, reservando-o para entregas finais ou quando solicitado.
2. **Implementação Direta**: Implemente as correções e melhorias de ponta a ponta de forma autônoma.
